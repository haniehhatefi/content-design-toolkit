# Module 2 — UX Writing Standards

This module translates the voice and tone foundations from [Module 1](../01-foundations/README.md) into practical writing standards for the most common interface patterns.

---

## Guidance levels

Every document in this module uses three levels of guidance. These levels are marked inline throughout.

| Level | Label | Meaning |
|---|---|---|
| **Rule** | `Rule` | Must be followed. Deviating requires a documented reason. |
| **Recommendation** | `Rec` | Should be followed in most cases. Justified exceptions are acceptable. |
| **Contextual** | `C` | Depends on your product, audience, or situation. Apply with judgement. |

This distinction matters because treating every guideline as an absolute rule makes standards brittle and hard to apply. Knowing whether something is a rule or a recommendation gives writers the information they need to make good decisions — and to explain those decisions to others.

## What this module covers

### Microcopy patterns

Guidance for writing the specific text types that appear most frequently in digital products.

| Document | What it covers |
|---|---|
| [Error messages](microcopy-patterns/error-messages.md) | Validation errors, system errors, page-level error states |
| [Buttons and CTAs](microcopy-patterns/buttons-and-ctas.md) | Primary, secondary, and destructive action labels |
| [Form fields](microcopy-patterns/form-fields.md) | Labels, placeholder text, helper text, and validation messages |
| [Empty states](microcopy-patterns/empty-states.md) | First-use, cleared, and no-results states |
| [Confirmation dialogs](microcopy-patterns/confirmation-dialogs.md) | Reversible and irreversible action confirmations |
| [Onboarding](microcopy-patterns/onboarding.md) | First-use orientation, progressive disclosure, tooltips |

### Content components

Guidance for writing within reusable interface components.

| Document | What it covers |
|---|---|
| [Notifications](content-components/notifications.md) | Alerts, banners, toasts, and system messages |
| [Tooltips](content-components/tooltips.md) | Contextual help text triggered by hover or focus |
| [Helper text](content-components/helper-text.md) | Persistent contextual guidance within forms and inputs |
| [Navigation labels](content-components/navigation-labels.md) | Menu items, tabs, breadcrumbs, and wayfinding labels |

## AI readiness note

These documents are structured to serve as grounding material for the AI prompt library in [Module 3](../03-ai-content-creation/README.md). Each pattern document follows a consistent format, with explicit rules and examples that can be referenced directly in a prompt.

When using these standards as AI grounding:
- Include the relevant pattern document in full as context
- Reference the guidance level (rule, recommendation, contextual) explicitly in your prompt
- Use the review checklist at the end of each document to evaluate AI output
