# Module 1 — Foundations

This module defines the fundamental standards that govern how content should sound and what it should achieve across your digital product.

## What this module covers

| Document | What it does |
|---|---|
| [Voice principles](voice-principles.md) | Defines the qualities that should be consistent across all content |
| [Tone spectrum](tone-spectrum.md) | Explains how tone adapts to context while voice stays stable |
| [Brand voice audit template](brand-voice-audit-template.md) | A repeatable process for assessing existing content against your voice principles |
| [Content principles](content-principles.md) | The broader design principles that govern how content is structured and sequenced |

## When to start here

Start with this module if you are:

- Establishing or reviewing content standards for a product team for the first time
- Joining a team that has existing content and want to understand what voice it currently has
- Writing a brief for a content project that needs to explain your approach
- Preparing for a content audit

## How these documents connect

**Voice principles** establish *what your content sounds like* — the stable qualities that should be recognisable regardless of context.

**Tone spectrum** establishes *how your content adapts* — the way those stable qualities express themselves differently in a confirmation message versus a critical error.

**Content principles** establish *how your content is designed* — the structural and strategic decisions that make content work, not just sound good.

**The audit template** gives you a process for measuring whether existing content reflects these standards.
